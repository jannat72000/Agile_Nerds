# 🎓 AgileNerds – Full-Stack Online Learning Platform

**AgileNerds** is a modern and dynamic Learning Management System (LMS) designed to connect students with expert educators. Built with a student-centric approach, this platform empowers learners to master new skills while providing instructors with a robust suite of tools to manage their digital classrooms effectively.

---

## 🏗️ Full-Stack Architecture
The project is built using a modern **Full-Stack (MERN-style)** architecture, ensuring a clean separation between the user interface and the server-side logic.

### **💻 Frontend (Client-Side)**
* **Library:** React.js (Component-Based Architecture).
* **Styling:** Bootstrap 5 & CSS3 (Fully Responsive Design).
* **Routing:** React Router DOM for seamless Single Page Application (SPA) navigation.
* **State Management:** React Hooks (`useState`, `useEffect`) for dynamic data handling.

### **⚙️ Backend (Server-Side)**
* **Environment:** Node.js.
* **Framework:** Express.js.
* **Database:** MongoDB / SQL (Managing User, Teacher, and Course data).
* **API:** RESTful API integration for smooth communication between front and back end.

---

## 🚀 Key Modules & Dashboard Functionality

### **👨‍🏫 Teacher (Instructor) Dashboard**
The instructor module serves as a complete command center for educators:
* **Centralized Analytics:** View course performance and student enrollment metrics (`TeacherDashboard.js`).
* **Course Lifecycle Management:** Full CRUD operations to add, edit, or remove courses and lessons (`AddCourse.js`, `TeacherMyCourses.js`).
* **Student Tracking:** Monitor and manage students who have joined specific courses (`MyUsers.js`).
* **Account Control:** Professional profile management and secure credential updates (`TeacherProfileSets.js`, `TeacherChangePass.js`).

### **👨‍🎓 User (Student) Dashboard**
A personalized interface designed to make the learning journey intuitive:
* **Personalized Hub:** Monitor active learning paths and track progress (`Dashboard.js`).
* **Learning Library:** Quick access to enrolled content and course history (`MyCourses.js`).
* **Smart Discovery:** Interests-based recommendations and bookmarks to save high-priority courses (`RecommendedCourses.js`, `FavoriteCourses.js`).
* **Security Settings:** Intuitive tools for profile updates and account security (`ProfileSetting.js`, `ChangePass.js`).
